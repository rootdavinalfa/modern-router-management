Wire the Toaster theme to the same resolved theme (sonner accepts `theme="light"|"dark"|"system"`). Do NOT introduce next-themes' ThemeProvider if the existing toggle already works — sonner's theme prop can be fed from the same state; if the existing mechanism is localStorage-only and non-reactive, extend ThemeToggle minimally so the current theme is readable via a small hook/context or CSS-class observer. Keep it simple; do not rebuild the theme system.
